## Key Concepts Learned

- **Service decoupling:** Compute and storage should operate independently
- **Static content hosting:** S3 can serve publicly accessible objects
- **Web server deployment:** EC2 can host front-end applications

Definitions:<br>
- **EC2:** Virtual server for compute workloads
- **S3:** Object storage service for static assets
